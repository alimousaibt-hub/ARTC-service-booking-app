Service Centre Bookings

Sign in with your Microsoft work account to access and update your SharePoint booking files.

Uses your existing work credentials. The app reads and writes only to SharePoint files you already have access to — nothing is stored externally.

If sign-in is blocked by your organisation, click Enter demo mode to test the interface first.

Connect to SharePoint

One-time setup. Your settings are saved in this browser — agents only do this once.

How to find your site URL: Open any booking Excel file in SharePoint and copy everything up to /sites/YourSiteName from the address bar.
Expected file path: [Folder]/[BRANCH]/[Branch Month Year].xlsx
Example: Service Bookings/RAK/RAK June 2026.xlsx
Files must be named exactly: RAK June 2026.xlsx, SZR June 2026.xlsx, etc.
If a file doesn't exist yet the app will warn you and work in local mode for that branch.
